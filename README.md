# 云岭森林公园

基于 Three.js 的交互式三维自然场景漫游与图形学算法演示系统。

## 运行

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可运行。生产构建使用：

```bash
npm run build
npm run preview
```

## 交互

- 轨道观察模式：鼠标拖动旋转，滚轮缩放。
- 第一人称漫游：点击“漫游模式”后，使用 `WASD` 移动，鼠标控制视角，`Shift` 加速。
- 右侧面板：调整时间、天气、地形起伏、湖面波速和粒子密度。
- 调试图层：显示地形网格、贝塞尔路径和碰撞范围。
- `F`：在轨道观察和第一人称漫游之间切换。

## 图形学模块

- 程序化高度场地形：基于多层正弦函数生成顶点高度和顶点颜色。
- GLSL 动态水面：顶点着色器进行时间驱动的波形位移。
- 天气粒子系统：维护粒子位置、速度、重生和密度控制。
- Catmull-Rom / 贝塞尔式观景路径：用于展示场景内的动态路径运动。
- 包围盒碰撞：限制漫游相机穿过木屋等场景对象。
