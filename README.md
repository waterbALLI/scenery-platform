# 云岭森林公园

基于 Three.js 的交互式三维自然场景漫游与图形学算法演示系统。

## 运行

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可运行。生产构建使用：

```bash
npm run build
npm run preview
```

## 交互

- 轨道观察模式：鼠标拖动旋转，滚轮缩放。
- 第一人称漫游：点击“漫游模式”后，使用 `WASD` 移动，鼠标控制视角，`Shift` 加速。
- 右侧面板：调整时间、天气、地形起伏、湖面波速和粒子密度。
- 地形算法：可切换原始波纹高度场、柏林噪声和侵蚀地形。
- 网格密度：可切换 45×45、70×70、100×100、130×130 地形网格。
- 视野流式加载：地形按 44×44 世界单位切块，围绕相机维护 5×5 区域，离开范围后自动卸载。
- 自适应 LOD：近景使用高密度网格，远景和高空视角自动使用低密度网格，并用裙边减弱块间接缝。
- 调试图层：显示地形网格、贝塞尔路径和碰撞范围。
- `F`：在轨道观察和第一人称漫游之间切换。
- 高空俯视：从控制面板进入高空倾角视角，查看扩大后的完整地图。

## 图形学模块

- 程序化高度场地形：基于多层正弦函数生成顶点高度和顶点颜色。
- 柏林噪声地形：基于多层梯度噪声生成连续自然起伏。
- 侵蚀地形：基于噪声坡度和山谷项模拟简化的侵蚀地貌。
- 山脊分形噪声：使用 ridged multifractal 生成山脊和峰线。
- 域扭曲噪声：使用 domain warping 改变噪声采样域，获得更自然的地貌结构。
- 热侵蚀双缓冲：在地形块生成时进行多轮坡面物质搬运，保留固定种子以保证流式加载的确定性。
- 水文掩膜水面：河道和湖盆由全局水文函数生成，水面三角形根据地形与水位裁剪，避免悬空和穿岸。

## 流式加载说明

`src/world/terrain.js` 保存全局坐标下的地形算法、侵蚀和水文函数；`src/world/terrain-worker.js` 在 Web Worker 中生成地形块；`src/world/world.js` 负责 5×5 地形块的加载、卸载、LOD、植被和水面。这样相机移动到远处后，旧块会被回收，新块会根据相同的固定种子重新生成。
- GLSL 动态水面：顶点着色器进行时间驱动的波形位移。
- 天气粒子系统：维护粒子位置、速度、重生和密度控制。
- Catmull-Rom / 贝塞尔式观景路径：用于展示场景内的动态路径运动。
- 包围盒碰撞：限制漫游相机穿过木屋等场景对象。
